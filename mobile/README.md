# Be The Hero - Mobile

![React Native](https://img.shields.io/badge/React%20Native-0.61-blue) ![Expo](https://img.shields.io/badge/Expo-37.0.3-lightgrey) ![Axios](https://img.shields.io/badge/Axios-0.19.2-blue)

## Sobre o Projeto
O **mobile** do Be The Hero foi desenvolvido em **React Native** com **Expo**, proporcionando uma interface intuitiva para que doadores possam visualizar e contribuir com casos cadastrados pelas ONGs.

## Tecnologias Utilizadas
- **React Native** (SDK 37.0.0)
- **Expo** 37.0.3
- **React Navigation** 5.1.4
- **Axios** 0.19.2
- **Intl** 1.2.5 (Formatação internacional de valores)
- **Expo Mail Composer** 8.1.0 (Envio de e-mails pelo app)
- **React Native Gesture Handler** 1.6.0
- **React Native Reanimated** 1.7.0
- **React Native Safe Area Context** 0.7.3
- **React Native Screens** 2.2.0

## Instalação e Configuração

### Pré-requisitos
Certifique-se de ter instalado:
- Node.js + npm/yarn
- Expo CLI (`npm install -g expo-cli`)

### Passos para rodar o projeto
1. Acesse o diretório do mobile:
   ```sh
   cd mobile
   ```
2. Instale as dependências do projeto:
   ```sh
   npm install
   ```
3. Inicie o servidor Expo:
   ```sh
   npm start
   ```
4. Para testar no dispositivo, use o aplicativo **Expo Go** e escaneie o QR Code gerado no terminal.
5. Para rodar no emulador Android:
   ```sh
   npm run android
   ```
6. Para rodar no emulador iOS (macOS com Xcode):
   ```sh
   npm run ios
   ```

## Uso
Após iniciar o servidor Expo, a aplicação estará disponível para testes em dispositivos móveis ou emuladores.
