# Be The Hero - Frontend

![React](https://img.shields.io/badge/React-16.13.1-blue) ![Axios](https://img.shields.io/badge/Axios-0.19.2-blue) ![React Router](https://img.shields.io/badge/React%20Router-5.1.2-blue)

## Sobre o Projeto
O **frontend** do Be The Hero foi desenvolvido em **React** e tem como objetivo fornecer uma interface intuitiva para ONGs se cadastrarem e gerenciarem pedidos de ajuda, permitindo que usuários interessados possam contribuir.

## Tecnologias Utilizadas
- **React** 16.13.1
- **React Router DOM** 5.1.2
- **Axios** 0.19.2
- **React Icons** 3.9.0
- **React Testing Library**

## Instalação e Configuração

### Pré-requisitos
Certifique-se de ter instalado:
- Node.js + npm/yarn

### Passos para rodar o projeto
1. Acesse o diretório do frontend:
   ```sh
   cd frontend
   ```
2. Instale as dependências do projeto:
   ```sh
   npm install
   ```
3. Inicie o servidor do React:
   ```sh
   npm start
   ```

## Uso
Após iniciar o servidor, o frontend estará disponível em:
- **Web:** `http://localhost:3000`
